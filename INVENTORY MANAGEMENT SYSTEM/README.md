## PROJECT OVERVIEW
The **Inventory Management System** is an interactive, web-based software dashboard developed using **Python** and **Streamlit**. It provides small-to-medium enterprises and operations teams with real-time stock monitoring, automated low-stock threshold notifications, product addition workflows, and dynamic stock update capabilities.

The core objective of this application is to streamline stock tracking, prevent inventory stockouts, and provide immediate insight into key financial metrics such as overall inventory valuation.

---

## KEY FEATURES & CAPABILITIES
* **Real-time KPI Dashboard:** Instantly calculates total product varieties, cumulative stock quantity, total overall inventory valuation ($), and low-stock item counters.
* **Automated Low-Stock Threshold Alerts:** Automatically flags items with stock quantities below **10 units** using visual warning cards.
* **Dynamic Product Catalog:** View full stock listings with real-time category filtering (e.g., Electronics, Furniture, Stationery).
* **Interactive Product Onboarding:** Input forms with instant validation for seamlessly adding new products to memory.
* **Instant Stock Quantity Updates:** Adjust item quantities dynamically without restarting the application using Streamlit's session state persistence.
